IMAGES FOLDER
=============
Place all your image files here.

Required images:
- IU_logo.png  : IU logo for title page (or comment out that line in main.tex)

Your thesis images (examples):
- architecture.png : System architecture diagram (referenced in Chapter 3)
- screenshot.png   : System UI screenshot (referenced in Chapter 4)
- figure_X.png     : Any other figures

Accepted formats: .png, .jpg, .pdf
Recommended: .png or .pdf for crisp rendering on Overleaf

HOW TO REFERENCE:
\includegraphics[width=0.9\textwidth]{images/your_filename}
(do NOT include the .png/.jpg extension -- LaTeX auto-detects)
